# AMW 2026: International Workshop on Data Management

Official portal for the international academic conference **Alberto Mendelzon International Workshop (AMW 2026)**. The goal was to transform a legacy-structured site into a modern, fast, and accessible platform for researchers worldwide.

![AMW 2026 website](/images/projects/amw2026-preview.png)
*Responsive layout optimized for desktop and mobile navigation.*

---

### Challenges and solutions

- **Information clarity:** Structuring calls for papers, deadlines, scientific committees, and travel guides in a clear, legible interface.
- **Performance:** Built with **Vite + React** and styled with **Tailwind CSS**, achieving near-instant loads and optimal Lighthouse scores (Core Web Vitals).
- **Continuous deployment:** Integrated with Vercel for automatic updates whenever the event schedule changes.
